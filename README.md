# 心意手账

移动端送礼决策 Demo。React / Vinext / Cloudflare Workers，D1 保存记录，R2 保存照片。

## 页面与链路

- **送礼**：左右切换整张月历，年份单独选择；生日与节日标记；不选日期展示回忆卡，进入朋友档案；选择日期展示人物卡，进入已绑定对象和场景的礼物推荐。
- **＋**：可上拉展开的底部卡片；朋友档案入口进入通讯录，朋友列表直接进入挑礼物。
- **朋友档案**：顶部头像切换；基础信息编辑；原始文字、照片记录与模拟关键词总结；轻量性格、偏好问卷；双向礼物邮票墙和详情。
- **推荐**：50 份示例礼物，按预算、已有偏好和送礼历史排序；收藏、换一批、登记送出。不提供商品购买。
- **我的**：统计、双向礼物墙；按朋友分组的可展开收纳夹，与朋友页面使用同一份礼物记录。

## 数据与访问

`db/schema.ts` 和 `drizzle/` 定义迁移。应用通过 prepared D1 SQL 保存手账，版本号检查阻止并发覆盖。已登录用户按账号隔离；公开演示访客首次加载时获得随机 HttpOnly SameSite Cookie，并按访客会话隔离演示数据。不同浏览器会话互不可见，关闭登录不会回退到账号数据。前端不以 localStorage 作为数据源。

问卷使用唯一 token，`/q/:token` 展示轻量问题，提交到服务器后更新原邀请人的朋友档案。问卷 API 本身允许持 token 填写，并阻止重复提交；公开 Demo 的持 token 问卷可匿名回传给邀请人的演示手账；问卷 token 不包含档案明文。主手账 API 按登录账号或随机演示会话隔离。

AI 关键词、礼物推荐均为确定性的 Demo 模拟，不调用模型。轻量性格问卷不等同于 MBTI 或心理诊断。礼物价格为示例。

## 视觉

奶油纸底、浅蓝细线、砖红小按钮、低饱和绿色与杏色；复古手账、二维手绘，保留苹果、蝴蝶结、星星。素材位于 `public/art`，不得替换成 emoji、3D 图片或默认商业仪表盘组件。

## 开发验证

- `node node_modules/typescript/bin/tsc --noEmit`
- `node scripts/run-framework.mjs build`
- `node tests/integration.mjs`：在独立 Miniflare 数据库测试增改删、保存、线索整理、问卷匿名回传、重复提交、身份隔离及 R2 上传。
- 托管环境预览使用 `sites-preview start "$PWD"`。

生产发布通过 Sites workflow。不要将本地开发身份回退用于生产；`NODE_ENV=production` 下未登录 API 返回 401。
